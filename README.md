ChatGPT 활용 내용 및 질문·답변 기록

이번 11주차 영화 보드 실습을 진행하면서 ChatGPT를 활용해 JavaScript와 HTML, CSS의 개념을 이해하고 코드 작성 과정에서 궁금했던 부분을 해결하는 데 도움을 받았다.

코드는 직접 작성하였으며, ChatGPT에는 주로 수업에서 배운 개념의 의미와 사용 방법, 코드가 작동하는 원리에 대해 질문하였다. 특히 JavaScript를 이용해 영화 카드를 생성하는 방법과 정렬 기능이 작동하는 원리를 이해하는 데 도움을 받았다.

질문 및 답변 예시

1. 질문: JavaScript의 document.createElement()와 appendChild()는 어떤 역할을 하나요?

답변: document.createElement()는 HTML 요소를 JavaScript로 새롭게 만드는 기능이고, appendChild()는 만들어진 요소를 부모 요소 안에 추가하는 기능이다. 이를 이용하면 HTML에 카드를 일일이 작성하지 않아도 JavaScript로 여러 개의 영화 카드를 생성할 수 있다.

활용 내용: 영화 데이터를 이용해 카드 6개를 자동으로 생성하는 원리를 이해하는 데 참고하였다.

2. 질문: sort()와 [...list]를 함께 사용하는 이유는 무엇인가요?

답변: sort()는 배열의 요소를 정렬하는 함수이지만 원본 배열 자체를 변경한다. [...list]를 사용하면 기존 배열을 복사한 새로운 배열을 만들 수 있으므로 원본 영화 데이터는 유지하면서 정렬할 수 있다.

활용 내용: 평점순, 최신 개봉순, 제목순 정렬 기능을 구현할 때 원본 영화 배열이 변경되지 않는 이유를 이해하였다.

3. 질문: localeCompare()는 무엇이고 일반적인 숫자 정렬과 어떤 차이가 있나요?

답변: localeCompare()는 문자열을 언어와 지역에 맞는 순서로 비교하는 함수이다. 숫자는 뺄셈으로 크기를 비교할 수 있지만, 한글 제목은 문자열 비교 기능을 이용해야 가나다순으로 정렬할 수 있다.

활용 내용: 영화 제목을 가나다순으로 정렬하는 기능을 이해하고 구현하는 데 참고하였다.

느낀 점

이번 실습을 통해 HTML에 영화 카드를 직접 작성하는 방식과 JavaScript를 이용해 데이터를 기반으로 카드를 자동 생성하는 방식의 차이를 알게 되었다. 또한 배열 복사와 정렬 함수, DOM 요소 생성 등의 개념을 실제 영화 보드에 적용하면서 수업에서 배운 내용을 더 잘 이해할 수 있었다.
